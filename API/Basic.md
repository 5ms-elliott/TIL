## エンドポイント 
アプリケーションがAPIにリクエストを送る際の「窓口」となる特定のURLのことです。  
API（Application Programming Interface）は、異なるアプリケーション間でデータや機能をやり取りするためのルールや仕組みです。  
エンドポイントは、そのAPIが提供する機能やデータにアクセスするための具体的な場所であり、通常はURL（Uniform Resource Locator）やURI（Uniform Resource Identifier）の形で表されます。   
例えば、GitHub APIでリポジトリ情報を取得する場合、https://api.github.com/repos/octocat/Hello-World がエンドポイントとなり、このURLにHTTPリクエストを送ることでデータを取得できます。 

### APIとエンドポイントの違い 

**API**: サービス全体の仕組みやルール。例えると「レストランそのもの」。  
**エンドポイント**: API内の個別のアクセス窓口。例えると「注文カウンター」。  
**URL**: エンドポイントまでの正確な住所。例えると「カウンターの場所を示す住所」 。
