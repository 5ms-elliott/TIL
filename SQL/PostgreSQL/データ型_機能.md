## JSON型
SONデータをテキストではなくバイナリ形式(0or1の2進数)で効率的に保存し、高速な検索やインデックス作成が可能。

## 配列型（Array）
カラムの中に配列データを直接格納できる。  
（例: text[]やinteger[]）

## カスタムデータ型・関数・演算子
ユーザーが独自のデータ型や関数、演算子を自由に定義できる。

## マテリアライズドビュー 
### ビューとの違い  
ビュー　・・・クエリに名前を付けて保存したもの。クエリの定義のみでデータは保持していない。  
  →参照するたびにSQLが実行される為、パフォーマンスに影響する。 
マテリアライズドビュー　・・・クエリの結果をディスク上に物理的に保存するデータべースオブジェクト。 
### 使用例 
ダッシュボードやレポート用の集計クエリ（毎回重い集計をしたくない場合）  
バッチ処理の結果を高速に参照したい場合  
データウェアハウスでの分析クエリの高速化 
### 基本的な使い方 
作成　　(作成と同時に、クエリが実行されて結果が保存される) 
```
CREATE MATERIALIZED VIEW daily_sales_summary AS 
SELECT 
    DATE(ordered_at) AS order_date, 
    SUM(amount)      AS total_amount, 
    COUNT(*)         AS order_count 
FROM orders 
GROUP BY DATE(ordered_at); 
```
(データを保存せずに定義だけ作りたい場合) 
```
CREATE MATERIALIZED VIEW daily_sales_summary 
WITH NO DATA AS 
SELECT 
    DATE(ordered_at) AS order_date, 
    SUM(amount)      AS total_amount, 
    COUNT(*)         AS order_count 
FROM orders 
GROUP BY DATE(ordered_at); 
```
リフレッシュ  
```REFRESH MATERIALIZED VIEW daily_sales_summary; ```  
削除  
```DROP MATERIALIZED VIEW daily_sales_summary; ```

## クォートの使い分け 

ダブルクオート（"）：識別子（カラム名やテーブル名など）を囲む  
シングルクオート（'）：文字列リテラルを囲む 

## 文字列の連結 


| 方法 | SQL構文 | 特徴 | 
| --- | --- | --- |
| パイプライン演算子 | string1 \|\| string2 | NULLが含まれていると全体がNULLになる。 |
| CONCAT関数 | CONCAT(string1, string2, ...) | 複数の引数を指定可能。NULLを自動で無視して結合する。 |
| CONCAT_WS 関数 | CONCAT_WS(separator, string1, ...) | 区切り文字 (WS: With Separator) を指定して結合できる。NULL値は無視される。 |
