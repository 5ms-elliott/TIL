## ARRAY_AGG()
複数のレコードの値を一つの配列にまとめて表示するための集計関数。  
ARRAY_AGGは、GROUP BYと組み合わせて使うのが一般的。これにより、特定のカテゴリに属する複数の値を1つのレコードに集約可能。
```
SELECT
    グループ化したいカラム,
    ARRAY_AGG(集約したいカラム)
FROM
    テーブル名
GROUP BY
    グループ化したいカラム;
```

### 例: 注文ごとの商品リストをまとめる  
order_detailsというテーブルがあり、各注文（order_id）に複数の商品ID（product_id）が紐づいているとする。
|order_id|product_id|quantity|
|--|--|--|
|101|200129|2|
|101|218882|1|
|102|532847|3|
|102|200129|1|  

このテーブルから、注文ごとに購入された商品IDを一覧で表示したい場合、ARRAY_AGGが非常に役立つ。
```
SELECT
    order_id,
    ARRAY_AGG(product_id) AS ordered_products
FROM
    order_details
GROUP BY
    order_id;
```
実行結果:

|order_id|ordered_products|
|--|--|
|101|{200129, 218882}|  
|102|{532847, 200129}|  

ARRAY_AGGを使うことで、order_idが同じレコードのproduct_idが1つの配列にまとめられ、関連するデータを1行で確認できるようになる。
